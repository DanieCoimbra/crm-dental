## 1. Visão Geral da Arquitetura & Tecnologias

- **Linguagem:** Go 1.26
- **Driver PostgreSQL:** `github.com/jackc/pgx/v5/pgxpool` (High-performance connection pooling)
- **Gerador de Código:** `sqlc` v2 (`sql_package: "pgx/v5"`)
- **Padrão de Persistência:** Repositórios limpos atuando como Adapters sobre o pacote compilado pelo SQLC.
- **Padrão Arquitetural:** Clean Architecture (Handlers ➔ Core Services ➔ Repository Adapters ➔ SQLC Queries ➔ PostgreSQL).

## 3. Configuração do SQLC (`sqlc.yaml`)

```yaml
version: "2"
sql:
  - schema: "db/schema/schema.sql"
    queries: "db/queries"
    gen:
      go:
        package: "sqlc"
        out: "db/sqlc"
        sql_package: "pgx/v5"
        emit_json_tags: true
        emit_prepared_queries: false
        emit_exact_table_names: false
```

## 4. Estratégia do Pooler de Conexões (`pgxpool.Pool`)

Em `internal/database/database.go`, a conexão GORM será substituída pelo gerenciador de conexões nativo do `pgx/v5`:

```go
package database

import (
	"context"
	"log"
	"os"

	"dental-crm-api/db/sqlc"

	"github.com/jackc/pgx/v5/pgxpool"
)

var (
	Pool    *pgxpool.Pool
	Queries *sqlc.Queries
)

func Connect() {
	dsn := os.Getenv("DATABASE_URL")
	if dsn == "" {
		log.Fatal("❌ DATABASE_URL não configurada.")
	}

	config, err := pgxpool.ParseConfig(dsn)
	if err != nil {
		log.Fatalf("❌ Erro ao parsear DSN: %v", err)
	}

	// Configuração otimizada para Supabase Pooler (Session Mode porta 5432)
	config.MaxConns = 25
	config.MinConns = 5

	pool, err := pgxpool.NewWithConfig(context.Background(), config)
	if err != nil {
		log.Fatalf("❌ Erro ao conectar ao banco via pgxpool: %v", err)
	}

	if err := pool.Ping(context.Background()); err != nil {
		log.Fatalf("❌ Erro de ping no banco: %v", err)
	}

	Pool = pool
	Queries = sqlc.New(pool)
	log.Println("✅ Conectado com sucesso via pgx/v5 e SQLC!")
}
```

## 5. Mapeamento de Tipos de Dados (PostgreSQL ↔ Go)

| PostgreSQL Type | GORM Anteriores | SQLC / `pgx/v5` Go Type |
| :--- | :--- | :--- |
| `BIGINT GENERATED BY DEFAULT AS IDENTITY` | `uint` | `int64` (convertido no Adapter) |
| `VARCHAR` / `TEXT` | `string` | `string` |
| `TIMESTAMPTZ` | `time.Time` | `time.Time` / `pgtype.Timestamptz` |
| `NUMERIC(10, 2)` | `float64` | `float64` / `pgtype.Numeric` |
| `BOOLEAN` | `bool` | `bool` |
